#+title: Research Harness Test Lab

Concurrent deep-research harness comparison lab. See =lab.org=.

* Fast path

#+begin_src sh
cp env.example .env
$EDITOR .env
./bin/research-lab setup
./bin/research-lab doctor
./bin/research-lab matrix --case DR-001 --parallel 4 --model z-ai/glm-5.3-flash --dry-run
./bin/research-lab matrix --case DR-001 --parallel 4 --model z-ai/glm-5.3-flash --strict
#+end_src

The default matrix runs StarIntel Auto Research CL, InternScience ResearchHarness, GPT Researcher, and Hugging Face Open Deep Research concurrently through OpenRouter. Upstreams are pinned in =config/harnesses.json=; benchmark instructions live in =guidelines/auto-research.org=; experiment cases live in =cases/=; isolated results land under =runs/=.
